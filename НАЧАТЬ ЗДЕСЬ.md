# TaskFlow — проект для портфолио .NET

1. Дважды нажмите **Start TaskFlow.cmd**.
2. Откройте **http://127.0.0.1:5080** в браузере.
3. Создайте заявку, назначьте исполнителя и попробуйте взять её в работу.
4. Посмотрите историю изменений и раздел «Обзор команды».

Данные сохраняются в `src/TaskFlow.Api/App_Data/taskflow.db`. При следующем запуске ваши изменения останутся. Стартовые заявки и участники вымышлены.

В этой рабочей папке уже подготовлен SDK. При передаче исходников на другой компьютер нужен .NET 10 SDK. Сборка интерфейса уже включена, Node.js для простого запуска не требуется.

Что показать работодателю:

- README.md — английское описание проекта и инструкция запуска;
- docs/screenshots — настоящие скриншоты приложения;
- src/TaskFlow.Api — C# API, EF Core, правила и история;
- tests/TaskFlow.Tests — тесты правил и API;
- frontend/src — исходники React;
- docs/ARCHITECTURE.md — схема данных и объяснение решений;
- docs/INTERVIEW-GUIDE.md — вопросы для самостоятельного разбора.

Это учебный pet-проект, созданный с помощью ИИ. Перед собеседованием важно разобраться в коде и внести собственное изменение. Проект не включает вход в аккаунт и не предназначен для публичной работы с реальными данными.
